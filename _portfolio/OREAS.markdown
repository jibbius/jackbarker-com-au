# OREAS Enterprise Web Platform

A sophisticated enterprise-level web platform developed for ORE Research, integrating multiple complex systems to create a specialized e-commerce solution for the mineral reference materials industry. This project represents a complete digital transformation from legacy systems to a modern, integrated web platform.

## 🎯 **Project Overview**

ORE Research specializes in producing and selling mineral reference materials for the mining and analytics industries. This project involved creating a comprehensive web platform that seamlessly integrates three critical business systems:

1. **WordPress CMS & Custom Store** - Customer-facing website with specialized e-commerce
2. **MYOB Advanced Integration** - Enterprise ERP system as source of truth
3. **Product Search Module** - Advanced search with real-time inventory synchronization

### **Integration Complexity**
- **Source of Truth**: MYOB Advanced serves as the master system for all customer, product, and order data
- **Real-time Sync**: Live integration ensuring data consistency across all systems
- **Loose Coupling**: Independent modules designed for maintainability and scalability
- **Enterprise Grade**: Built to handle complex business workflows and multiple developer teams

## 🚀 **Key Features & Capabilities**

### **Advanced E-commerce Platform**
- **Specialized Product Search**: Custom search engine for technical mineral reference materials
- **Real-time Inventory**: Live stock level checking against MYOB Advanced
- **Custom Checkout Process**: Tailored workflow for specialized industry requirements
- **Order Management**: Complete order lifecycle from cart to fulfillment

### **MYOB Advanced Integration**
- **Customer Synchronization**: Automatic WordPress user creation from MYOB contacts
