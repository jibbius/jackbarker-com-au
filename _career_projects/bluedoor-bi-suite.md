Introduced a comprehensive suite of reporting tools to the Bluedoor Platform using Sisense technology.

## Key Responsibilities

- **ETL Scripting** - Developed scripts for data transformation and loading into new reporting database
- **Domain Knowledge Support** - Provided expertise to Database Architect for optimal data structure design
- **Sisense Configuration** - Configured elasticube structures within Sisense product for optimal performance
- **User Migration** - Migrated user permissions hierarchy into new reporting tools via scripting and JSON API
- **Dashboard Design** - Created user-friendly dashboards for business intelligence needs
- **Post-Implementation Support** - Provided ongoing support and troubleshooting after go-live

## Technologies Used

- Sisense Business Intelligence platform
- ETL scripting and data transformation
- JSON API integration
- Database design and architecture
- Dashboard and visualization design

## Impact

Successfully modernized reporting capabilities for the Bluedoor platform, providing users with enhanced business intelligence tools and improved data accessibility.
